##### 08. Circles _scatter_boxplot_timeline_dumbbell_bubble
- Circles (точечная диаграмма) — для быстрого сравнения отдельных значений и поиска выбросов.
- Scatter (диаграмма рассеяния) — для анализа взаимосвязи между двумя показателями и выявления аномалий.
- Boxplot (ящик с усами) — для оценки распределения, разброса и стабильности данных.
- Timeline (временной график / линия времени) — для анализа динамики, трендов и сезонности во времени.
- Dumbbell (гантельная диаграмма) — для наглядного сравнения двух состояний (до/после, план/факт).
- Bubble (пузырьковая диаграмма)— для одновременного анализа трёх показателей и выявления лидеров и проблемных зон.
- [просмотр](08._Circles%20_scatter_boxplot_timeline_dumbbell_bubble/screenshots_circles.pdf)

##### 09. Maps
- Maps (карты) — для визуализации географических данных, сравнения показателей по регионам и выявления территориальных закономерностей и аномалий.
- [просмотр](09._Maps/%23screenshots__maps.pdf)

##### 10. Parameters
Параметры — это пользовательские переменные для динамического управления логикой расчётов, фильтрацией и поведением визуализации, позволяющие интерактивно менять анализ без изменения структуры данных.
[просмотр](10._parameters/%23screenshots_parameters.pdf)

##### 11. Sets
-Сеты — это группа выбранных элементов в данных, которая позволяет сравнивать, сегментировать или выделять объекты для анализа; другими словами, это «логическая коробка», в которую ты кладёшь нужные значения, чтобы с ними работать отдельно от остальных»
-[просмотр](11._sets/screenshots_сеты.pdf)

**Параметр = ручка управления анализом (пользователь выбирает значение), а сет = группа элементов для сравнения и сегментации данных.**

##### 12. Groups and hierarchies
-Группа (Group) — объединяет элементы в одну категорию для упрощения анализа, а иерархия (Hierarchy) — организует уровни данных для drill-down от общего к деталям.
-[просмотр](12._groups%20and%20hierarchies/screenshots_groups_hierarchies.pdf)

##### 13. Tooltip
- Tooltips — всплывающие подсказки в Tableau, которые при наведении показывают дополнительную информацию и детали, не перегружая визуализацию.

##### 14. Measures and dimensions

- Dimensions — поля, описывающие данные и формирующие категории и разрезы анализа.

##### 15. Analytics_tab  
- Box Plot — полный ящик с усами для распределения, используй, когда сравниваешь группы и хочешь увидеть разброс + выбросы.
- Trend Line — линия общей тенденции (рост/падение), лучше всего для понимания долгосрочного направления и корреляции.
- Forecast — настоящий прогноз будущего с доверительным интервалом, используй только на временных рядах с сезонностью и минимум 2–3 годами данных.
- Reference Line — линия сравнения (среднее, максимум, константа), универсальный инструмент, когда нужно сравнить каждое значение с эталоном.
- Reference Band — заштрихованная полоса между двумя значениями, лучше всего для выделения «нормального» диапазона (например, 5K–12K шагов).
- Distribution Band — полосы ±1/2/3 стандартных отклонений или перцентили, используй, когда анализируешь разброс и хочешь статистически значимые зоны.
- Cluster — автоматическая кластеризация точек, используй, когда хочешь найти скрытые группы в данных без ручной сегментации.
  [просмотр](15_ Analytics_tab/15_analytics_tab.pdf)
